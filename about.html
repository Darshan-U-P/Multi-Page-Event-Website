ABOUT EVENTSPHERE

Bringing people closer to great ideas.

EventSphere is a student mini project that demonstrates a clean, multi-page event discovery website served by Apache HTTP Server inside Docker.

Explore Events ↗
01 / DISCOVER

Find experiences

Browse sample events across technology, creativity, and entrepreneurship, presented in one consistent interface.

02 / CONNECT

Bring communities together

Event pages highlight the topic, date, location, and illustrative schedule so visitors can understand each listing quickly.

03 / BUILD

Learn by building

The project uses semantic HTML, responsive CSS, Apache httpd, Docker Compose, and a bind mount for simple live editing.

PROJECT STACK

Simple tools. Real workflow.

HTML5CSS3Apache httpd 2.4DockerDocker Compose

This website is a demonstration only. Event information is sample content; it does not provide real ticketing, sign-ups, or event management.
